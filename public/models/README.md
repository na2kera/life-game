# public/models

Blender で作った 3D モデルを置く場所。ファイルが無いモデルはコード側の仮形状で表示される
（`src/view/assets.ts`）。置き換えはファイルを置くだけでよく、コードの変更は不要。

## 書き出し規約

- 形式: **glb**（glTF Binary）。ファイル名は下表のとおり
- 単位: **メートル**（Blender の Unit Scale = 1.0）。マス 1 個 = 1m 四方
- 原点: **底面中央**（モデルの一番下の面の中心に Origin を置く）
- 向き: **Blender の +Y が前方**（Forward）、+Z が上。glTF 書き出し時の「+Y Up」はオンのまま
  （three.js では前方が -Z、上が +Y になる）
- マテリアル: **Principled BSDF のみ**（他のシェーダーノードは glTF に書き出されない）
- テクスチャは glb に埋め込む
- マテリアル名に `tint` を含むマテリアルは、ゲーム側でプレイヤー色・マス種別色に上書きされる
  （例: コマの車体を `body_tint` にする）

## モデル一覧

| ファイル | 用途 | 大きさの目安 | 補足 |
| --- | --- | --- | --- |
| `piece.glb` | プレイヤーのコマ（車） | 幅 0.25 × 長さ 0.4m 程度 | 1 マスに最大 4 台並ぶ。前方 = Blender +Y |
| `tile.glb` | マス 1 個 | 0.86m 四方・高さ 0.12m 程度 | マスの種類ごとの色は `tint` マテリアルで付く |
| `roulette.glb` | ルーレットの回転する円盤 | 半径 0.5m | XY 平面（Blender）に寝かせ、上面が +Z。出目 1 の扇形の中心を +Y（前方）に置き、上から見て時計回りに 2, 3, …, 10 を等分で並べる。数字もモデル（テクスチャ）に含める。針や台座はコード側で描く |
